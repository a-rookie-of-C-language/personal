### 1.常量：

例如 1，2，3，4，这些不会改变的量叫常量。

```cpp
printf("%d",3);
```

### 2.变量：

顾名思义，可以改变的量

```cpp
int a=0;
printf("%d",a);//0
a=1;
printf("%d",a);//1
```

这里的a就是变量，它的值由0，变为了1

关于更高级的解释将会在后面深度解释。这里初学就这样理解就行
