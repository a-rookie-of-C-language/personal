### 什么是函数，为什么有函数这个概念

函数就是把一段代码封装起来，重复使用而避免大量重复代码。简化代码，使代码更简洁，高效。

简单例子

我们要找两个数的最大值，我们不可能每次都写一个if语句来找最大值，所以我们把它包装成max函数，每次找两个数的最大值时就可以调用函数。

### 函数的组成

一个简单的找最大值的函数

```cpp
int max(int a,int b){
    if(a>b){
        return a;
    }else{
        return b;
    }
}
```

#### 1.函数头

```cpp
int max(int a,int b)
```

int 函数的返回值类型

找最大值，我们是需要一个值作为最大值，所以函数中需要返回一个值，这个值的类型为int 所以开头为int

max()

函数的名字，调用函数时会用到。

int a,int b

形参

**什么是形参？** 
形参全称叫做“形式参数”，也是一个虚拟的参数，在定义方法的时候使用的参数，形参是方法被调用时用于接收实参值的变量。

形参没有实际的值，他的值是从实参调用过来的
**什么是实参？** 
实参全称叫做“实际参数”，顾名思义就是实际存在的参数，实参可以是常量、变量、表达式、类等，实参必须要有确定的值。

```cpp
​
int max(int a,int b){//a,b是形式参数
    if(a>b){
        return a;
    }else{
        return b;
    }
}
 
​int main(){
    max(4,6);//4,6是实际参数
}
```

#### 3.返回值

函数最重要的部分

除了返回值为void的函数，任何函数都要有返回值

比如max函数中有return语句，这就是函数的返回值。max函数我们要的是一个值，所以我们返回一个值。

注意，一旦函数运行到return语句或者函数结尾，函数就会停止执行

```cpp
#include<stdio.h>
int max(int a,int b);//函数声明
int max(int a,int b){
    if(a>b){
        return a;
    }else{
        return b;
    }
}
int main(){
    printf("%d",max(4,6));//6
}
 
​
```
